# Physics of Hobbies

[physicsofhobbies.com](https://physicsofhobbies.com)

La física detrás de las herramientas que usas en el taller: cómo funcionan, qué miden de verdad y
cómo sacarles el máximo partido.

El sitio analiza especificaciones técnicas de instrumentos de medida y explica qué significan en la
práctica: qué mide realmente un número de la ficha, cuál importa para tu caso y cuál es puro
reclamo comercial. No es un canal de reseñas — los productos no se prueban, se interpretan sus
datos publicados. Está contado sin rodeos en
[/metodologia](https://physicsofhobbies.com/metodologia/).

Este repositorio contiene el frontend: un sitio estático hecho con Astro. Incluye enlaces de
afiliado de Amazon, declarados en cada página.

```bash
npm install
npm run dev
```
